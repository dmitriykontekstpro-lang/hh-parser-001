# ☁️ Подробная инструкция: Как развернуть парсер на облачном сервере (VPS)

Самый надежный и дешевый способ запустить такого бота — арендовать виртуальный сервер (VPS). Это как удаленный компьютер, который работает 24/7.

---

## 🏗 Шаг 1. Подготовка кода
Чтобы легко перенести код на сервер, лучше всего загрузить его на GitHub.

1. Создайте **новый репозиторий** на [GitHub.com](https://github.com).
   - Назовите его, например, `hh-scraper`.
   - Сделайте его **Private** (Частным), чтобы никто не украл ваш код.
2. Загрузите файлы из папки `hh-scraper-cloud` в этот репозиторий (можно через кнопку "Upload files" на сайте GitHub или через Git, если умеете).
   - **ВАЖНО**: Не загружайте файл `.env`. Загрузите только `.env.example`. Ваши пароли должны вводиться только на сервере!

---

## 🛒 Шаг 2. Покупка сервера (VPS)
Вам нужен сервер с поддержкой Docker. Так как мы запускаем браузер (Playwright), нам нужно немного оперативной памяти.

**Рекомендуемые характеристики:**
- **OS**: Ubuntu 22.04 или 24.04
- **CPU**: 1 или 2 ядра
- **RAM**: 2 GB (минимум 1 GB, но может быть мало для браузера)
- **Disk**: 20-30 GB SSD

**Где купить (примеры):**
- **Aeza** (РФ/Европа) — хорошие цены, принимают карты РФ.
- **Timeweb Cloud** (РФ) — надежно, удобно.
- **Selectel** (РФ) — профессионально, но чуть сложнее.

После покупки вам пришлют IP-адрес сервера (например, `45.12.34.56`) и пароль от пользователя `root`.

---

## 💻 Шаг 3. Подключение к серверу
Вам нужно открыть терминал (командную строку) на вашем компьютере.

1. **Windows**: Нажмите `Win + R`, введите `cmd`, нажмите Enter.
   (Или используйте PowerShell / VS Code Terminal).
2. Введите команду подключения:
   ```bash
   ssh root@ВАШ_IP_АДРЕС
   # Пример: ssh root@45.12.34.56
   ```
3. Вас спросят "Are you sure...?". Напишите `yes`.
4. Введите пароль (он **не будет отображаться** при вводе). Нажмите Enter.

🎉 Если вы увидели приветствие `Welcome to Ubuntu...` — вы внутри сервера!

---

## 🐳 Шаг 4. Установка Docker (Если не установлен)
Выполните эти команды по очереди (просто копируйте и вставляйте правой кнопкой мыши):

1. Обновим систему:
   ```bash
   apt update && apt upgrade -y
   ```

2. Установим Docker одной командой (скрипт сам все сделает):
   ```bash
   curl -fsSL https://get.docker.com -o get-docker.sh
   sh get-docker.sh
   ```

3. Проверим, что работает:
   ```bash
   docker --version
   ```
   *Если показало версию — всё отлично.*

---

## 🚀 Шаг 5. Запуск бота

### 1. Скачиваем код
Теперь скачаем ваш код с GitHub на сервер. 
*Если вы не использовали GitHub, вы можете просто перетащить папку с кодом через программу FileZilla.*

Если через GitHub (потребуется ввести логин и токен/пароль):
```bash
git clone ССЫЛКА_НА_ВАШ_REPO.git
cd hh-scraper
```

### 2. Настраиваем секретные данные
Создадим файл `.env` прямо на сервере.

1. Скопируем шаблон:
   ```bash
   cp .env.example .env
   ```
2. Откроем его для редактирования:
   ```bash
   nano .env
   ```
3. Вы увидите редактор. Стрелочками на клавиатуре наведите курсор и **впишите свои реальные данные**:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

4. Чтобы сохранить:
   - Нажмите `Ctrl + O`, затем `Enter` (Сохранить).
   - Нажмите `Ctrl + X` (Выйти).

### 3. Запускаем!
Самый важный момент. Эта команда скачает браузеры, установит библиотеки и запустит бота в "фоновом" режиме.

```bash
docker compose up -d --build
```
*(Если пишет command not found, попробуйте `docker-compose up -d --build` с дефисом)*.

---

## 🕵️‍♂️ Шаг 6. Управление и Проверка

### Как посмотреть логи (что делает бот)?
```bash
docker compose logs -f
```
(Нажмите `Ctrl + C`, чтобы выйти из просмотра логов).

### Как остановить бота?
```bash
docker compose down
```

### Как обновить код (если вы что-то поменяли на GitHub)?
```bash
git pull
docker compose up -d --build
```

## ✅ Финальная проверка
1. Откройте своего Telegram-бота.
2. Напишите `/start`.
3. Напишите `/run`.
4. Бот должен ответить, что задача запущена.

Теперь сервер работает 24/7. Можно закрывать терминал (`exit`), бот продолжит работать.
