# ✅ Чек-лист запуска

## 1. База Данных (Supabase)
- [ ] Создать проект на [supabase.com](https://supabase.com).
- [ ] Открыть **SQL Editor** в панели Supabase.
- [ ] Скопировать и выполнить код из файла `setup_schema.sql` (лежит в корне проекта).
- [ ] В таблицу `search_queries` добавить хотя бы одну строку (например: `Python`).

## 2. Telegram Бот
- [ ] Написать `@BotFather` команду `/newbot`.
- [ ] Задать имя и юзернейм бота.
- [ ] Скопировать полученный `TOKEN`.
- [ ] Написать боту `@userinfobot` (или любому другому, например Get My ID) и узнать свой `CHAT_ID`.

## 3. Настройка программы
- [ ] Переименовать файл `.env.example` в `.env`.
- [ ] Открыть `.env` любым текстовым редактором (Блокнот, VS Code).
- [ ] Вставить свои данные:
  - `SUPABASE_URL`: Ссылка на проект (Project URL из настроек API).
  - `SUPABASE_KEY`: Секретный ключ (service_role secret из настроек API).
  - `TELEGRAM_BOT_TOKEN`: Токен от BotFather.
  - `TELEGRAM_CHAT_ID`: Ваш ID чата.

## 4. Запуск
**На компьютере (Windows):**
- [ ] Дважды кликнуть на `run.bat`.
- [ ] Если появятся ошибки, убедиться, что установлен Python 3.10+.

**На сервере (Docker):**
- [ ] Установить Docker и Docker Compose.
- [ ] Загрузить папку проекта на сервер.
- [ ] В папке проекта выполнить: `docker-compose up -d --build`.

## 5. Проверка
- [ ] Открыть свой бот в Telegram.
- [ ] Нажать `/start`.
- [ ] Нажать `/run` для тестового запуска сбора вакансий.
- [ ] Проверить, появились ли новые записи в таблице `vacancies` в Supabase.
