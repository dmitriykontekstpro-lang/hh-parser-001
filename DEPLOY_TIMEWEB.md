# ☁️ Инструкция по запуску на Timeweb Cloud

Timeweb Cloud — отличный выбор, у них удобная панель и есть встроенная консоль (можно работать прямо из браузера).

---

## Шаг 1. Создание сервера

1.  Зарегистрируйтесь/войдите в [Timeweb Cloud](https://timeweb.cloud).
2.  Нажмите кнопку **+ Создать** -> **Облачный сервер**.
3.  **Выбор системы (Образ)**:
    - Нажмите на вкладку **Маркетплейс**.
    - В поиске напишите `Docker`.
    - Выберите образ **Docker** (обычно он на базе Ubuntu).
    - *Почему это круто?* Docker уже будет установлен, вам не придется вводить лишние команды!

4.  **Конфигурация**:
    - Регион: **Россия (Москва или СПб)**.
    - Тариф: Выберите любой, где есть **2 GB RAM (ОЗУ)** или больше. Обычно это тарифы линейки "Cloud" или "HighFreq".
    - Диск: 15-20 ГБ хватит (NVMe).

5.  **Настройки доступа**:
    - Уберите галочку "SSH-ключ" (если не умеете пользоваться), оставьте **Пароль**.
    - Придумайте пароль или нажмите "Сгенерировать". **ОБЯЗАТЕЛЬНО СОХРАНИТЕ ЕГО!**

6.  Нажмите **Заказать**.
    - Через 1-2 минуты сервер будет готов. В панели появится его IP-адрес (например `45.130.xxx.xxx`).

---

## Шаг 2. Подключение (через браузер)

Вам даже не нужна программа на компьютере!

1.  В панели Timeweb нажмите на ваш новый сервер.
2.  В меню сверху нажмите вкладку **Консоль**.
3.  Откроется черное окно терминала прямо в браузере.
4.  Вас могут спросить `login:`. Введите `root` и нажмите Enter.
5.  Вас спросят `Password:`. Введите тот пароль, который вы сохранили при создании.
    - *Внимание*: Когда вы вводите пароль, **символы не появляются**. Это нормально! Просто введите и нажмите Enter.

🎉 Вы внутри!

---

## Шаг 3. Загрузка Парсера

Так как мы выбрали образ с Docker, он уже есть. Сразу переходим к коду.

Самый простой способ — скачать код через Git.

1.  Установите Git (если его нет, но обычно есть):
    ```bash
    apt update && apt install git -y
    ```

2.  Клонируем репозиторий (замените ссылку на свою!):
    *Если вы еще не залили код на GitHub, сделайте это. Если не хотите, используйте FileZilla (см. ниже).*
    ```bash
    git clone https://github.com/ВАШ_ЛОГИН/hh-scraper.git
    ```
    *Вас попросит Username (ваш логин GitHub) и Password (для пароля нужно создать Personal Access Token в настройках GitHub, обычный пароль не подойдет).*

    **💡 Альтернатива без GitHub (через командную строку):**
    Просто создадим папку и загрузим файлы "руками" через SFTP.
    Но проще всего использовать программу **FileZilla** на вашем компьютере:
    - Хост: `sftp://IP_ВАШЕГО_СЕРВЕРА`
    - Пользователь: `root`
    - Пароль: ваш пароль.
    - Просто перетащите папку `hh-scraper-cloud` с вашего ПК на сервер в папку `/root`.

---

## Шаг 4. Настройка и Запуск

Предположим, вы загрузили код в папку `hh-scraper-cloud`.

1.  Заходим в папку:
    ```bash
    cd hh-scraper-cloud
    ```

2.  Создаем файл с настройками `.env`:
    ```bash
    cp .env.example .env
    nano .env
    ```

3.  Откроется редактор. Впишите свои данные:
    - Сперва сотрите старое (клавиша Del или Backspace).
    - Вставьте свои `SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. (Чтобы вставить в консоль, обычно работает `Ctrl+Shift+V` или правая кнопка мыши -> Paste).

4.  Сохраняем:
    - `Ctrl + O`, `Enter`
    - `Ctrl + X`

5.  Запускаем!
    ```bash
    docker compose up -d --build
    ```
    *(Пойдет скачивание, сборка... подождите 2-3 минуты)*.

---

## Шаг 5. Всё работает?

1.  Проверьте, что контейнер запущен:
    ```bash
    docker compose ps
    ```
    Вы должны увидеть статус `Up`.

2.  Посмотрите логи (что пишет бот):
    ```bash
    docker compose logs -f
    ```
    Если увидите "Scheduler started" отправьте команду `/run` боту в Телеграм.

**Готово!** Теперь можно закрыть вкладку браузера, бот работает на сервере Timeweb.
