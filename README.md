# Облачный Парсер HH.ru

Это надежный парсер для HH.ru, готовый к работе в облаке. Он сохраняет вакансии в Supabase и управляется через Telegram-бота.

## ✨ Возможности
- **Двухэтапный сбор**:
  1. Сначала ищет вакансии по вашим запросам.
  2. Затем заходит в каждую новую вакансию и собирает детали (Зарплата, Описание, Компания).
- **Управление с телефона**: Полный контроль через Telegram (Запуск, Статус, Уведомления).
- **Умная фильтрация**:
  - Игнорирует вакансии, которые уже есть в базе.
  - Фильтрует по **Стоп-словам** (например, "Senior", "Lead", если вам они не нужны), которые задаются в базе.
- **Защита от блокировок**: Использует Playwright с настройками скрытности (stealth) для обхода защиты Cloudflare/ботов.
- **Работа по расписанию**: Автоматически запускается каждые 12 часов (настраивается).

## 🛠 Предварительная настройка

### 1. База данных (Supabase)
1. Создайте проект в [Supabase](https://supabase.com).
2. Перейдите в **SQL Editor** в панели управления Supabase.
3. Скопируйте и выполните код из файла `setup_schema.sql` (лежит в папке проекта).
4. Зайдите в **Table Editor** и добавьте данные:
   - В таблицу `search_queries` добавьте поисковые запросы (например: `Python разработчик`, `Data Scientist`).
   - В таблицу `stop_words` добавьте стоп-слова (например: `Senior`, `Lead`, `1С`).

### 2. Telegram Бот
1. Напишите @BotFather в Telegram, чтобы создать нового бота.
2. Получите **TOKEN** бота.
3. Узнайте свой **CHAT_ID** (можно написать боту @userinfobot).

## 🚀 Установка и Запуск

### Вариант 1: Docker (Рекомендуется для облака/VPS)
Самый простой способ запустить на сервере.

1. **Создайте файл .env**:
   Переименуйте `.env.example` в `.env` и заполните ваши данные:
   ```ini
   SUPABASE_URL=ваша_ссылка
   SUPABASE_KEY=ваш_ключ
   TELEGRAM_BOT_TOKEN=токен_бота
   TELEGRAM_CHAT_ID=ваш_ид
   ```

2. **Запустите контейнер**:
   ```bash
   docker-compose up -d --build
   ```

### Вариант 2: Локальный запуск (Windows)
1. Установите Python 3.10+.
2. Запустите файл `run.bat` (он сам установит зависимости и браузеры).
3. Или вручную через консоль:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   python -m uvicorn backend.main:app --reload
   ```

## 📱 Управление через Telegram

- `/start` — Проверка связи, бот должен ответить.
- `/status` — Проверить, работает ли расписание.
- `/run` — **Принудительный запуск** сбора вакансий прямо сейчас.

## 📂 Структура проекта
- `backend/scraper.py` — Логика парсера и обхода блокировок.
- `backend/tasks.py` — Сценарий сбора: Поиск -> Фильтр -> Сбор деталей -> Уведомление.
- `backend/bot.py` — Логика Telegram бота.
- `Dockerfile` — Настройки для упаковку в контейнер (для деплоя на сервер).
